### F1：矛盾论

**来源**：《矛盾论》1937

**核心原理**：任何事物内部都包含对立统一的矛盾。矛盾有主次之分，主要矛盾有主要方面和次要方面。抓住主要矛盾的主要方面，就抓住了问题的关键。

**适用场景**：多方力量对立、利益冲突、需要判断优先级、竞争格局分析

**操作步骤**：
1. 列出问题中所有对立面（成本 vs 质量、速度 vs 稳定、短期 vs 长期……）
2. 判断哪个矛盾是**主要矛盾**——解决它是否能带动其他矛盾的解决？
3. 在主要矛盾中，找**主要方面**——矛盾的哪一面决定了事物当前的性质？
4. 分析矛盾的**转化条件**——什么情况下主次会互换？
5. 制定针对主要矛盾主要方面的策略

**金句**：
- 「捉住了这个主要矛盾，一切问题就迎刃而解了。」
- 「矛盾着的两方面中，必有一方面是主要的，他方面是次要的。其主要的方面，即所谓矛盾起主导作用的方面。事物的性质，主要地是由取得支配地位的矛盾的主要方面所规定的。」

### F2：实践论

**来源**：《实践论》1937

**核心原理**：认识从实践中来，经过感性认识→理性认识的飞跃，再回到实践中检验。认识是螺旋上升的过程，不是一次完成的。

**适用场景**：理论与实践脱节、认知迷茫、学习方法、验证假设

**操作步骤**：
1. 你当前处于认识的哪个阶段？感性（模糊印象）还是理性（结构化理解）？
2. 如果停留在感性阶段，需要什么实践来推动飞跃？
3. 如果已有理性认识，如何回到实践中去检验？
4. 检验结果是否要求修正认识？（螺旋上升）
5. 警惕两种偏差：**经验主义**（只看经验不看理论）和**教条主义**（只看理论不看实践）

**金句**：
- 「实践、认识、再实践、再认识，这种形式，循环往复以至无穷，而实践和认识之每一循环的内容，都比较地进到了高一级的程度。」
- 「感觉到了的东西，我们不能立刻理解它，只有理解了的东西才更深刻地感觉它。」

### F3：认识循环

**来源**：《人的正确思想是从哪里来的？》1963

**核心原理**：正确思想只能从社会实践中来。物质→意识→物质，即：从客观外界到主观认识，再从主观认识到改造客观世界。一个正确认识往往需要多次反复才能完成。

**适用场景**：认知来源追问、思维方法论、验证判断是否靠谱

**操作步骤**：
1. 这个认识是从哪来的？是亲身实践还是二手信息？
2. 它经过了实践检验吗？检验了几次？
3. 如果未经检验，设计一个最小实践去验证
4. 检验结果反馈回来后，修正认识，进入下一个循环

**金句**：
- 「人的正确思想是从哪里来的？是从天上掉下来的吗？不是。是自己头脑里固有的吗？不是。人的正确思想，只能从社会实践中来。」
- 「一个正确的认识，往往需要经过由物质到精神，由精神到物质，即由实践到认识，由认识到实践这样多次的反复，才能够完成。」

### F4：持久战三阶段

**来源**：《论持久战》1938

**核心原理**：在力量不对等的长期斗争中，经历三个阶段——战略防御、战略相持、战略反攻。相持阶段最关键。战略上藐视对手（有信心），战术上重视对手（每一步都认真）。

**适用场景**：资源不对等的长期竞争、以弱对强、需要分阶段推进的战略

**操作步骤**：
1. 判断你当前处于哪个阶段：防御（求生存）、相持（积蓄力量）、还是反攻（主动出击）？
2. 每个阶段的核心任务不同：
   - **防御期**：保存实力，不做决战，积小胜为大胜
   - **相持期**：最关键也最漫长，持续积蓄力量，等待转化时机
   - **反攻期**：条件成熟后集中力量，打歼灭战
3. 评估：从当前阶段到下一阶段，需要什么条件？
4. 贯彻双重态度：**战略上藐视**（相信最终能赢）+ **战术上重视**（每个具体行动都全力以赴）

**金句**：
- 「在战略上我们要藐视一切敌人，在战术上我们要重视一切敌人。」
- 「最后的胜利往往在于再坚持一下的努力之中。」

### F5：星星之火

**来源**：《星星之火，可以燎原》1930

**核心原理**：小而坚定的力量，在正确条件下可以发展为不可阻挡的力量。关键不在于现在有多大，而在于是否站在了正确的趋势上。

**适用场景**：从零起步、资源极少、别人不看好但你相信方向正确

**操作步骤**：
1. 你的"火种"是什么？（核心能力、独特资源、关键洞察）
2. "干柴"在哪里？（未被满足的需求、即将爆发的趋势）
3. 火种和干柴是否匹配？
4. 如何保护火种不被扑灭？（在力量弱小时避免正面对抗）
5. 如何制造"第一阵风"？（找到点燃的引爆点）

**金句**：
- 「星星之火，可以燎原。」
- 「它是站在海岸遥望海中已经看得见桅杆尖头了的一只航船，它是立于高山之巅远看东方已见光芒四射喷薄欲出的一轮朝日。」

### F6：游击十六字诀

**来源**：游击战争战术原则

**核心原理**：在力量弱于对手时，用灵活机动的方式与之周旋。不在对手强的地方硬碰，在对手弱的地方狠打。

**适用场景**：资源劣势下的竞争策略、灵活应对强大对手、战术层面的具体行动

**操作步骤**（十六字诀）：
1. **敌进我退**：对手在你的领域发力时，不要硬抗，保存实力，转移战场
2. **敌驻我扰**：对手停下来巩固时，用小动作持续骚扰，不让它舒服
3. **敌疲我打**：等对手分散注意力、疲于应对时，集中力量打击其薄弱点
4. **敌退我追**：对手收缩或放弃时，迅速填补空间，扩大战果

**应用原则**：
- 不打无准备之仗，不打无把握之仗
- 集中优势兵力打歼灭战（不要平均分配资源到所有方向）
- 灵活转换，不固守一种打法

**金句**：
- 「敌进我退，敌驻我扰，敌疲我打，敌退我追。」
- 「集中优势兵力，各个歼灭敌人。」

### F7：农村包围城市

**来源**：战略思想

**核心原理**：当正面进攻中心不可能成功时，从边缘、从对手忽视的地方开始，逐步积累力量，最终包围中心。

**适用场景**：市场进入策略、避开巨头正面竞争、从边缘切入

**操作步骤**：
1. 找到"城市"（对手的核心领地、主流市场）
2. 找到"农村"（对手忽视的、利润低但真实存在的边缘市场）
3. 在"农村"建立根据地——站稳脚跟，积累经验和资源
4. 从一个根据地扩展到多个，连成片
5. 时机成熟时，从包围到进攻"城市"

**金句**：
- 「农村是海洋，城市是岛屿。」
- 「枪杆子里面出政权。」（核心能力是一切的基础）

### F8：调查研究

**来源**：《反对本本主义》1930

**核心原理**：没有调查就没有发言权。一切结论产生于调查情况的末尾，而不是在它的先头。反对用本本（书本、理论、权威说法）代替实际调查。

**适用场景**：信息不足时的决策、挑战"常识"、验证假设、制定方案前的准备

**操作步骤**：
1. 承认自己不够了解情况（这是起点，不是丢人）
2. 确定调查对象：谁是当事人？谁最了解一线情况？
3. 设计调查方法：访谈、数据收集、实地观察
4. 调查时注意：
   - 既看整体也看典型个案
   - 既听领导也听基层
   - 既看数据也看故事
5. 调查完再下结论，结论必须能被调查事实支撑

**金句**：
- 「没有调查，没有发言权。」
- 「调查就像'十月怀胎'，解决问题就像'一朝分娩'。调查就是解决问题。」

### F9：实地考察

**来源**：《湖南农民运动考察报告》1927

**核心原理**：要了解真实情况，必须亲自到现场去看。坐在办公室里听汇报得到的信息，和亲眼看到的往往完全不同。别人说"坏"的东西，可能恰恰是"好"的。

**适用场景**：挑战主流叙事、发现被忽视的真相、亲自验证

**操作步骤**：
1. 现有认知来自谁？这些人有什么立场和偏见？
2. 确定必须亲自验证的核心事实
3. 去到一线、现场、用户身边
4. 用自己的眼睛看，不要带着预设结论
5. 特别注意：主流说法和你亲眼所见之间的差异，这个差异往往就是关键洞察

**金句**：
- 「一切所谓"过分"的举动……都有革命的意义。」（别人说的"问题"可能是"答案"）
- 「革命不是请客吃饭。」（真正的变革不可能让所有人舒服）

### F10：群众路线

**来源**：群众路线方法论

**核心原理**：从群众中来，到群众中去。领导者的正确意见不是凭空产生的，而是收集分散的群众意见，加以集中和系统化，然后再到群众中去检验。

**适用场景**：团队管理、收集用户需求、组织动员、民主决策

**操作步骤**：
1. **从群众中来**：广泛收集一线人员 / 用户 / 团队成员的意见和需求
2. **集中**：把分散的、零碎的意见加以分析、综合、系统化
3. **到群众中去**：把系统化后的方案拿回去，让群众讨论、检验、补充
4. **再集中、再到群众中去**：反复循环，不断完善
5. 注意：不是简单投票，而是**集中群众的智慧**——群众的分散意见可能各有片面性，集中后才是全面的

**金句**：
- 「从群众中集中起来又到群众中坚持下去，以形成正确的领导意见，这是基本的领导方法。」
- 「群众是真正的英雄，而我们自己则往往是幼稚可笑的。」

### F11：十大关系

**来源**：《论十大关系》1956

**核心原理**：复杂系统中存在多组需要平衡的关系。不能只顾一头，必须辩证地同时处理多个张力。每一组关系都不是非此即彼，而是寻找动态平衡。

**适用场景**：多目标冲突、资源分配、优先级平衡、系统性决策

**操作步骤**：
1. 列出你面对的所有需要平衡的关系对（参考以下清单）
2. 对每一组关系，判断当前是否失衡，偏向了哪一边
3. 失衡的根本原因是什么？
4. 制定调整方案，注意：调整不是翻转，而是向平衡点移动

**常见关系对**（可按需替换）：
- 重工业与轻工业 → **核心业务 vs 新业务**
- 沿海与内地 → **优势领域 vs 短板领域**
- 经济建设与国防 → **增长 vs 安全/稳定**
- 国家、集体与个人 → **组织利益 vs 个人利益**
- 中央与地方 → **集权 vs 放权**

**金句**：
- 「我们的方针是统筹兼顾、适当安排。」
- 「十个指头弹钢琴。」（不能只弹一个键）

### F12：两类矛盾

**来源**：《关于正确处理人民内部矛盾的问题》1957

**核心原理**：矛盾分两类——**对抗性矛盾**（根本利益冲突，需要斗争解决）和**非对抗性矛盾**（同一阵营内部分歧，需要协商解决）。搞错性质，后果严重：该斗争时软弱，该协商时搞对抗。

**适用场景**：内部分歧、团队矛盾、路线之争、判断该强硬还是该妥协

**操作步骤**：
1. 判断这个矛盾的**性质**：是根本利益冲突还是方法、认知上的分歧？
2. **对抗性矛盾**：利益根本不可调和 → 必须斗争、必须有一方让步或退出
3. **非对抗性矛盾**：目标一致但方法不同 → 通过讨论、批评、教育来解决
4. 警惕**性质转化**：非对抗性矛盾处理不当（压制、忽视），可能激化为对抗性矛盾
5. 对内部矛盾，核心方法是「团结—批评—团结」：从团结的愿望出发，经过批评或斗争，达到新的团结

**金句**：
- 「什么是人民内部的矛盾呢？……这是在人民利益根本一致的基础上的矛盾。」
- 「在一般情况下，人民内部的矛盾不是对抗性的。」
