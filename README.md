# 教员思维框架 (jiaoyuan-skill)

一个 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 自定义 Skill，将毛泽东核心著作蒸馏为可操作的思维框架，用于分析任何复杂问题。

**不是语录库，是思维工具。**

## 它能做什么

当你面对一个复杂问题时，用 `/jys` 触发这个技能，它会引导 Claude 用毛泽东的方法论帮你：

1. **识别矛盾** — 找出问题中的对立面，判断主要矛盾和次要矛盾
2. **调查现状** — 区分感性认识和理性认识，标记信息缺口
3. **选择框架** — 从 12 个思维框架中自动匹配最相关的 1-3 个
4. **辩证分析** — 看两面、析转化条件、从特殊到普遍再回到特殊
5. **制定策略** — 给出具体行动建议，分阶段推进

## 覆盖的 12 个思维框架

| 编号 | 框架 | 来源 | 适用场景 |
|-----|------|------|---------|
| F1 | 矛盾论 | 《矛盾论》1937 | 多方对立、利益冲突、判断优先级 |

| F3 | 认识循环 | 《人的正确思想是从哪里来的？》1963 | 思维方法论、验证判断 |
| F4 | 持久战三阶段 | 《论持久战》1938 | 以弱对强、长期竞争 |
| F5 | 星星之火 | 《星星之火，可以燎原》1930 | 从零起步、资源极少 |
| F6 | 游击十六字诀 | 游击战术 | 资源劣势下的灵活竞争 |
| F7 | 农村包围城市 | 战略思想 | 避开巨头、从边缘切入 |
| F8 | 调查研究 | 《反对本本主义》1930 | 信息不足、挑战常识 |
| F9 | 实地考察 | 《湖南农民运动考察报告》1927 | 挑战主流叙事、亲自验证 |

## 安装

将 `SKILL.md` 放入 Claude Code 的 skills 目录即可：

```bash
# 克隆到 Claude Code skills 目录
git clone https://github.com/lyq00177-arch/jiaoyuan-skill.git ~/.claude/skills/jiaoyuan-skill
```

## 使用

在 Claude Code 对话中，用以下任意方式触发：

- `/jys`
- `/jiaoyuan`
- `/教员`
- 或者直接说：「帮我用矛盾论分析一下……」「教员帮我想想……」「辩证分析一下……」

## 示例

```
> /jys
> 我想创业但资源有限，怎么跟大公司竞争？
```

Claude 会按五步工作流（识别矛盾 → 调查现状 → 选择框架 → 辩证分析 → 制定策略）逐步分析，每步停下来等你确认再继续。

## 设计原则

- **可操作 > 可背诵**：每个框架都有具体操作步骤，不只是理论描述
- **每步停下来**：不一口气倒出分析，而是逐步确认，避免基于错误假设一路狂飙
- **框架是工具，不是权威**：鼓励质疑框架的适用性，简单问题不硬套
- **引用原文佐证**：分析用现代语言，关键处引用原文，不模仿毛泽东的语气
